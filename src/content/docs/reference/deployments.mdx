## Funding a Test Account with Friendbot

You can fund any new Stellar public key with 10,000 testnet XLM for free:

<Tabs>
  <TabItem label="cURL">
```bash
curl "https://friendbot.stellar.org?addr=YOUR_STELLAR_PUBLIC_KEY"
```
  </TabItem>
  <TabItem label="PowerShell">
```powershell
Invoke-RestMethod -Uri "https://friendbot.stellar.org?addr=YOUR_STELLAR_PUBLIC_KEY"
```
  </TabItem>
  <TabItem label="JavaScript">
```javascript
await fetch(`https://friendbot.stellar.org?addr=${publicKey}`);
```
  </TabItem>

## Verifying Contracts via Stellar CLI

If you have `stellar-cli` installed, you can inspect the contracts on-chain:

```bash
# Query AgentTreasury contract info
stellar contract inspect --id CCBZLHEHRUBAHGB72ZZLNHBT4RURGTW2SSSQC4DJDDILVDG4VR55FEJL --network testnet

# Query X402Escrow contract info
stellar contract inspect --id CDJS3VHPBXVSFIPA6FUBVS3YXKUGZ75GQ7TQFVPMHBX3KHMREGGNMLFE --network testnet
```
