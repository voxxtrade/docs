The VoxTrade smart contract ecosystem is authored in **Rust** using the **Soroban SDK**. It is designed with strict separation of concerns between agent capital management and transaction escrow settlement.

---

## The Contract Pair

```
                   ┌─────────────────────────────┐
                   │    Merchant Admin Wallet    │
                   └──────────────┬──────────────┘
                                  │ Configures budgets & rules
                                  ▼
┌──────────────────────────────────────────────────────────────┐
│                    AgentTreasury Contract                    │
│  - Stores merchant working capital                           │
│  - Enforces 24-hour rolling spending allowance               │
│  - Grants authorized AI agent calling permissions            │
│  - Emergency pause / fund reclamation                        │
└──────────────────────────────┬───────────────────────────────┘
                               │ Disburses micro-payments
                               ▼
┌──────────────────────────────────────────────────────────────┐
│                     X402Escrow Contract                      │
│  - Holds locked escrow funds during voice call               │
│  - Verifies cryptographic SHA-256 preimages                  │
│  - Releases funds upon successful audio delivery             │
│  - Automated ledger timeout refunds                          │
└──────────────────────────────────────────────────────────────┘
```

## Storage Model & Soroban TTL (Time-to-Live)

Soroban uses state archival and rent mechanics. In VoxTrade:
- **Instance Storage**: Stores permanent configuration data (merchant admin address, agent public key, daily limit configuration). Automatically bumped with `env.storage().instance().extend_ttl(...)`.
- **Temporary / Persistent Storage**: Used for individual escrows in `X402Escrow`. Once an escrow is claimed or refunded, its storage key can be reclaimed to keep state bloat minimal.

## Contract Standards & Tooling

The contracts follow official Stellar development standards:
- **Soroban SDK**: v22+
- **Rust Toolchain**: 1.80+ with `wasm32-unknown-unknown` target
- **Testing**: Native in-memory Soroban test environment (`Env::default()`)
- **Deterministic Testing**: Mock ledger sequencing and time dilation testing
